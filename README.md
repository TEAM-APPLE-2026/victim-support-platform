# 🍎 Team Apple | victim-support-platform

AI 기반 유사 피해자 매칭 및 공동 대응 지원 플랫폼

흩어진 피해 사례를 정리하고 유사한 사건 그룹을 찾아, 피해자가 직접 참여 여부와 다음 대응을 선택하도록 돕습니다.

## 현재 상태

기획 및 초기 개발 준비 단계입니다. 이 저장소에는 프로젝트 문서와 기본 디렉터리만 있으며, 실행 가능한 애플리케이션은 아직 없습니다. 최종 서비스명, 기술 스택, 세부 역할은 팀 협의 후 확정합니다.

## 핵심 사용자 흐름

피해 작성 → 정보 확인·수정 → 유사 사건 추천 → 그룹 확인·참여 → 자료 준비·진행 확인

- AI가 추출한 업체·지점·날짜·금액은 사용자가 확인하고 수정합니다.
- 비슷한 글과 같은 사건을 구분하고, 추천 근거와 불일치 항목을 보여줍니다.
- 일치하는 그룹이 없으면 수동 그룹 생성이나 개인 대응 준비로 이어집니다.
- 결제 금액과 주장 피해액은 구분하며, 인원·금액의 집계 기준을 정의합니다.

## 구현 계획

| 단계 | 범위 |
| --- | --- |
| 기본 흐름 | DB·API 설계, 로그인·권한, 피해 등록·조회·수정, 사건 탐색·그룹 참여 |
| AI 연결 | 정보 추출·사용자 확인, 기존 그룹 추천·근거 표시 |
| 피해자 기능 확장 | 그룹 대시보드, 증거 관리, 내 사건·진행 현황 |
| 후속 기능 | 로펌 승인·사건 탐색, 제안서 비교, 투표·선정, 참여 확정·사건 운영 |

자동 클러스터링을 통한 새 그룹 제안은 기존 그룹 추천이 안정된 후 검토합니다. 위 표는 계획이며 구현 완료를 의미하지 않습니다.

## 시작하기

```bash
git clone https://github.com/TEAM-APPLE-2026/victim-support-platform.git
cd victim-support-platform
```

비공개 저장소이므로 초대 수락과 GitHub 인증이 필요합니다. 의존성 설치·서버 실행 명령은 기술 스택 확정 후 각 디렉터리 README에 추가합니다.

## 데이터와 접근 권한

- 실제 피해자 개인정보, 증거 원본, API 키, 비밀번호는 Git에 올리지 않습니다.
- 예시·합성 데이터와 실제 분석 결과를 구분하고 통계 출처·집계 기준을 남깁니다.
- 그룹의 공개 요약과 개인 원문·증거의 열람 권한을 분리합니다.
- 대응 안내는 출처를 확인해 제공하며, 법률 판단이나 결과를 보장하지 않습니다.
